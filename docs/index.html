PYiOS v1.0.0 Released

iPhone OS 2.x Emulator in Python

A lightweight ARMv7 binary compatibility layer powered by Unicorn Engine, Pygame, and PyOpenGL. Designed to run classic legacy iPhone OS apps directly on PC.

Download Release
Compatibility Notice: Application emulation is in active early development. Currently, iBeer (v2.0.3) is the primary fully tested and functional app.

Core Capabilities

ARMv7 CPU Execution: Powered by Unicorn CPU emulation to run compiled iOS binaries directly.
PowerVR SGX / OpenGL: Hardware-accelerated graphics pipeline combined with software Quartz rendering.
Objective-C Runtime: Dynamic message dispatching, class registration, and framework method resolution.
Native Decoders: Custom extractors for Apple CgBI PNG images and Core Audio Format (.caf) sound.
